# Audio Assets (heroic)

Audio layer assembled 2026-09-08 from a Kenney Music Loops CC0 track and original deterministic 44.1kHz PCM WAV SFX.

- `bgm_loop.ogg`: Kenney Music Loops CC0 — `Alpha Dance` (renamed for runtime use)
- `ui_click.wav`: input feedback
- `action_primary.wav`: primary action
- `danger_warning.wav`: danger cue
- `transition.wav`: state transition
- `result_success.wav`: success result
- `result_failure.wav`: failure result
