# 소드마스터즈 어센트 — Steam 스토어 설명 (한국어)

## 짧은 설명

탑 안의 모든 검사가 당신을 노리고 있다. 검술을 연마하고, 층을 오르고, 한 번에 한 층씩 살아남아라.

---

## 전체 설명

**소드마스터즈 어센트**는 탑 안의 모든 존재가 검사인 세계를 배경으로 한 턴제 로그라이트입니다. 당신 역시 검사입니다. 기술을 쌓고, 압박 속에서 스테미너를 관리하며, 층마다 더 강한 적과 더 어려운 선택이 기다리는 무한의 탑을 올라가세요.

전투는 포지셔닝 격자 시스템을 중심으로 설계되었습니다. 적과의 거리와 행(row) 위치가 어떤 공격이 적중하는지, 어떤 스킬이 닿는지, 그리고 각 행동이 얼마나 스테미너를 소모하는지를 결정합니다. 강한 타격을 위해 근접하거나, 회복 시간을 벌기 위해 물러나거나, 자리를 지키며 반격을 노리세요. 모든 선택은 스테미너를 소모하며, 스테미너를 회복하는 유일한 방법은 이동뿐입니다. 가만히 서 있는 것은 절대 무료가 아닙니다.

층을 클리어할 때마다 보상을 선택하세요. 장비는 능력치 상한을 바꾸고, 아이템은 위기 상황에서 선택지를 넓혀주며, 칭호는 캐릭터가 성장하는 방향을 바꿉니다. 같은 런은 두 번 없고, 같은 방식으로 싸우는 검사도 두 명 없습니다. 빌드는 층마다 진화하고, 그에 비례해 압박도 커집니다.

승리 조건 없이 무한히 올라가는 소드마스터즈 어센트는 기록의 게임입니다. 얼마나 높이 올라갔는지, 그리고 다음엔 무엇을 다르게 할 것인지.

## 주요 특징

- **포지셔닝 전투 시스템** — 거리와 행 위치가 공격의 적중 여부를 결정합니다. 당신과 동일한 규칙으로 싸우는 적을 상대로 5칸 격자를 활용하세요.
- **스테미너 경제** — 모든 행동은 공유 스테미너 풀을 소모합니다. 이동만이 유일한 회복 수단입니다. 소비와 회복의 리듬을 익혀야 더 오래 살아남을 수 있습니다.
- **깊이 있는 로그라이트 성장** — 런을 거듭하며 칭호, 장비, 능력을 해금하세요. 장비, 마법, 투척 아이템을 조합해 매번 다른 접근 방식을 시도하세요.
- **무한 탑 오르기** — 결승선이 없습니다. 당신의 최고 층수 기록만이 유일한 점수입니다. 매 런에서 이전 런이 가르쳐주지 않은 것을 배우게 됩니다.
- **빠르고 읽기 쉬운 세션** — 짧게 끝날 수도, 길게 이어질 수도 있습니다. 루프는 간결합니다: 이름 짓기 → 능력치 분배 → 전투 → 보상 → 반복.
