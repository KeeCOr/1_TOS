## 한 줄 소개

주사위 선택과 층별 성장으로 던전을 오르는 로그라이트 전술 RPG.
---

## 핵심 루프

```
유저가 현재 전장 상황(HP/SP/거리/행)을 확인한다
→ 메인 액션 5가지 중 하나를 선택한다 (공격/마법/방어/이동/아이템)
→ 서브액션 목록에서 세부 행동을 고른다
→ 주사위가 굴러 결과(명중/회피/피해/효과)가 결정된다
→ 층 클리어 시 성장 보상(스탯/스킬/아이템)을 선택한다
→ 다음 층의 새 적을 마주하며 다시 상황 확인으로 돌아간다
```

핵심 흐름: **상황 읽기 → 선택 → 주사위 결과 → 보상/성장 → 다음 위협**

## 게임 시스템 상세

### 전투 구조
- **전장 좌표:** 플레이어 시작 위치 1, 적 시작 위치 4 (거리 3)
- **행(Row) 시스템:** 행은 이동 서브액션으로만 변경. 공격은 같은 행에만 명중. 마법·아이템(투척)은 행 무관
- **메인 액션 5가지:** 공격 / 마법 / 방어 / 이동 / 아이템 사용
- **서브액션:** 22개 세부 선택지 (메인 액션별 상황에 맞게 노출)
- **주사위 체계:** 3단계 굴림 — 명중 판정 → 크리티컬/회피 분기 → 피해량 결정
- **방어 시스템:** 3단계 분기 (블록 / 회피 / 카운터)
- **스태미너 시스템:** 행동마다 스태미너 소모, 고갈 시 선택 폭 축소

### 성장과 빌드
- 층 클리어마다 스탯·스킬·아이템 보상 선택
- 로그라이트 구조: 매 판 빌드 방향이 달라짐
- localStorage 기반 3슬롯 세이브 (서버 없이 운영)

### HUD/UI 구조 (1280×720 고정)
- **상단 상황바:** 플레이어 HP/MP/ST + 층수/레벨 (좌) | 거리·행 일치 지표·적 의도 (중) | 적 HP/MP/ST·보스 마커 (우)
- **중앙 게임보드:** 배경 아트·캐릭터 스프라이트·원근 격자·부유 피해 텍스트·화면 이펙트
- **하단 전술 콘솔:** 액션 버튼 (좌) | 거리 미니맵·전투 로그 (중) | 적 능력·플레이어 버프/디버프 (우)

| 게임 | 핵심 행동까지 단계 수 | 핵심 재미 포인트 | 적용 교훈 |
|------|--------------------|-----------------|-----------|
| **Slay the Spire** | 튜토리얼 → 덱 확인 → 첫 전투 선택: 3단계, 약 90초 | 카드 시너지·빌드 다양성, 적 의도 공개로 예측 가능한 전략 | 적 다음 행동을 미리 표시해 계획 세우는 재미를 제공한다 |
| **Into the Breach** | 맵 로드 → 배치 확인 → 첫 이동 명령: 2단계, 약 30초 | 완벽한 정보 공개, 실수 없는 최적해 탐색의 퍼즐 쾌감 | 현재 위협과 대응 행동을 같은 화면에 배치해 스캔 시간을 최소화한다 |
| **Monster Train** | 첫 유닛 배치 → 전투 자동 진행 → 보상 선택: 3단계, 약 60초 | 층별 덱 빌딩, 수비·공격 라인 이중 관리 | 보상 선택 화면에서 다음 판의 전략 힌트를 함께 보여주면 재시작 동기가 강해진다 |

**이 프로젝트 적용 교훈:**  
규칙 설명보다 먼저 선택 가능한 상황(HP·거리·행·주사위)을 보여주고, 결과 화면에서 "다음 판 개선 포인트"를 바로 제안한다. 첫 의미 있는 선택까지 30초 이내, 첫 결과 피드백까지 60초 이내를 목표로 한다.

## 조작과 UX 원칙

- 주요 버튼은 44px 이상으로 유지하고, 화면당 CTA 강조색은 하나만 사용한다 (Von Restorff 효과)
- 버튼/선택지는 한 번에 5개 이하로 노출해 판단 부담을 줄인다 (Hick's Law)
- 400ms 이내 선택 피드백 제공 (Doherty Threshold)
- HUD 동일 레이어 요소는 겹치지 않게 배치하고, 겹침이 필요한 이펙트는 별도 depth/z-order 사용

### 🖥️ UX / UI
- **전투 피드백 타이밍 분리:** 현재 3단계 주사위 결과가 빠르게 연속 처리되는 경우 유저가 각 단계를 인식하지 못할 수 있음 — 명중 판정(0.3초 대기) → 크리티컬/회피 분기(0.2초 플래시) → 피해량 부유 텍스트(0.4초 유지) 순서로 각 단계에 딜레이와 사운드 큐를 분리 배치해 3단계 결과를 순차 체감하게 한다
- **첫 판 진행 시 조건별 힌트 오버레이:** 튜토리얼 완료 플래그 이전에 한해, 현재 상황(예: 거리 2 이상에서 공격 선택 시 "거리가 멀어 명중률 -30%입니다" 오버레이)을 행동 확인 직전에 반투명 레이어로 표시 — 텍스트 설명이 아닌 결과 예측 정보를 행동 직전에 제공
- **층 이동 전환 연출 최소화:** 층 클리어 후 보상 선택 → 다음 층 진입까지의 연출이 3초 이상이면 반복 플레이 시 피로감으로 작용 — 보상 확정 탭 후 1초 이내 다음 층 HUD가 로드되도록 트랜지션 시간을 최대 1.2초로 제한
- **행(Row) 상태 시각화 강화:** 현재 행 정보가 텍스트 지표로만 표시되는 경우, 배경 격자에 플레이어/적의 현재 행 위치를 색상 레이어(예: 플레이어 행 파란색, 적 행 붉은색)로 오버레이해 행 불일치 상황을 즉시 인식할 수 있게 한다

- **스팀 데모 → 유료 전환 퍼널 최적화:** 웹 무료 버전에서 5층 클리어 달성 시 "스팀 정식판에서 10층 이후 보스·특수 빌드 잠금 해제" 배너를 전투 결과 화면에 삽입 — 이미 재미를 느낀 직후에 구매 전환 유도, 무료판이 데모 역할을 하는 이 게임 구조에 적합
- **DLC 스킨/빌드팩:** 기본 무기 외 '마법사 빌드 팩', '도적 빌드 팩' 등 서브액션 세트를 DLC로 구성 — 코어 루프 변경 없이 빌드 다양성 확장, 스팀 DLC 형태로 개발 비용 최소화

### ⚙️ 기술적 개선
- **주사위 결과 재현 가능한 시드 저장:** 각 판의 주사위 시드값을 localStorage에 보관해 "이 판 다시 보기" 리플레이 기능 구현 가능 — 유저가 패배 원인을 분석하거나 커뮤니티에 공유할 수 있어 D1 리텐션과 입소문 효과 모두 기대
- **SVG → 비트맵 전환 자동화 파이프라인:** 현재 코드 드로잉·SVG 에셋을 수동으로 비트맵 교체하는 대신, sharp 또는 puppeteer 기반 빌드 스크립트로 SVG를 자동 래스터라이즈해 PNG로 변환 — 에셋 교체 공수 절감 및 UI/리소스 일관성 체감도 76% → 90%대 달성 가능
- **Electron 안정성 — 포트 충돌 방지:** 내장 HTTP 서버 포트를 고정값 대신 `portfinder` 라이브러리로 동적 탐색 후 바인딩 — 동일 PC에서 여러 인스턴스 실행 또는 포트 사용 중인 환경에서 발생하는 빌드/실행 안정성 70% 문제 해결
